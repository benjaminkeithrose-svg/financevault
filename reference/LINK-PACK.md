# Reference link pack

The official sources Financial Vault's tax and lending features rely on. The same list is in `link-pack.json` for the program to load.

- **Rates pages** keep the same address and are updated each July, so the link always shows the current figures.
- **Yearly guides** get a new address each year (e.g. `rental-properties-2026`, where 2026 means the 2025–26 year). Each has a pattern for next year's address.
- **Rulings** keep the same address; check the page still says it's current.
- Checked on 2026-09-26. Check again: July, after the new financial year's guides are published.
- Saved copies are in `sources/`; `SOURCES.md` lists what is saved and what is still needed.
- Items marked ⚠ weren't confirmed — open them once and update.
