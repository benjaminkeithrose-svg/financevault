## The rules

1. **Copy, never move or delete.** Leave every email and every original file
   exactly where it is. Don't archive, label, mark as read, reply to or forward
   any email.
2. **Attachments only — never click links.** If an email says "your statement is
   ready, log in to view it", don't follow the link. Add a line to the log
   instead (see below) so I can download it from the bank myself.
3. **Only financial paperwork.** Skip marketing, newsletters, receipts under $50
   (unless they're for property, tax deductions or a major purchase), and
   anything personal that isn't about money.
4. **Don't send anything anywhere.** Everything stays in the intake folder on
   this computer.
5. **When unsure, don't guess.** Put it in `_Not sure` and say why in the log.

## The folder to build

Create this inside the folder I've given you, called `Vault intake`:

```
Vault intake/
  <Owner name>/
    <Financial year, e.g. 2023-24>/
      <Document type>/
        2024-03-15 Westpac Choice statement.pdf
    Permanent/
      <Document type>/        ← things that don't belong to one year
    Identity documents/       ← licence, passport, Medicare, birth certificate
  _Not sure/
  _Duplicates/
  _intake-log.csv
```

- **Financial year** runs 1 July to 30 June: a document dated 15 March 2024 goes
  in `2023-24`. Use the year the document is *for* (a 2023-24 tax return lodged in
  August 2024 still goes in `2023-24`).
- **Permanent** is for things that cover many years: trust deeds, company
  constitutions, contracts of sale, loan contracts, leases, depreciation schedules.
- **File names:** `YYYY-MM-DD Who-from What.pdf` — the document's own date, then
  the bank, agency or business, then a few words. Keep the original file type.
- **Duplicates:** if the same document turns up twice (same file, or the same
  statement from two places), keep one and put the other in `_Duplicates`.

## The log

Keep `_intake-log.csv` with one row per item, columns:

`saved as, came from, document type, owner, financial year, note`

- **came from:** the email account, sender, subject and date — or the original
  file's folder and name.
- **note:** anything I should know: "only a link — download from the bank",
  "duplicate of …", "not sure if this is the trust's or mine", "password
  protected", "scanned, hard to read".
